How this is computed

Target = one cycle's copies (the pipeline's quantity per run ÷ runs per invented copy) × the T2 BPC Buffer ({{ t2_pct }}%). BPCs in tracked hangars count as one copy each at the configured runs per copy; invention attempts in flight convert at the configured chance. Attempts = the remainder ÷ chance, rounded up. Each attempt consumes one licensed run of a T1 copy: the copy target in runs is attempts × the T1 BPC Buffer ({{ t1_pct }}%), net of the copy stack (minus the BPO assumed to sit with it, each copy assumed to hold the blueprint's max runs) and the licensed runs on copy jobs in flight; copies are then made at max runs each. Pipelines sharing a blueprint draw from one pool. Inputs net once across all pipelines against stock and in-flight jobs; buy prices are the venue's raw quote, cost per run uses landed prices. Change the BPC Buffer percentages in Settings (Stockpile Buffer panel).
